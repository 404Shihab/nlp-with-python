# NLP Basics

## Basic Terminology

### 1. Text
Written language or textual data used as input for NLP.

### 2. Document
A particular piece of text, such as an article, email, or review.

### 3. Sentence
A group of words that forms a complete sentence.

### 4. Word
An individual word within a sentence.

### 5. Token
A small unit produced when text is split during tokenization.
A token can be a word, punctuation mark, or other text unit.

### 6. Corpus
A collection of documents or text used for NLP analysis.

## Relationship

Corpus
├── Document
│   ├── Sentence
│   │   ├── Word / Token
│   │   └── Word / Token
│   └── Sentence
└── Document
